## 〇、总评

第八轮完成了微信网关稳定性（自动重连/限流/媒体下载）和模型选择器过滤。本轮聚焦**对话框 UI 精简**——合并 agent + model 选择器到右下角，移除输入框旁的冗余选项卡，同时将设置页"技能与MCP"拆分为独立标签。

## 一、P1 · 右下角合并 Agent + Model 选择器（功能性升级 · 高优）

**痛点**：对话框输入框旁有 AgentSwitcher + ModelDropdown 两个选择器，底部状态栏也有 ModelDropdown——选择器冗余、UI 拥挤。用户反馈：右下角的 AgentSwitcher 选项卡够用，输入框旁不需要。

**现状**（源码级）：
- **输入框旁**：`AiComposerInput.tsx:271-272` 渲染 `<ModelDropdown />` + `<AgentSwitcher />`
- **底部状态栏**：`StatusBar.tsx:142` 渲染 `AiStatusBarControls`（含 ModelDropdown）
- **右下角**：`AiMiniWindow.tsx:356` 渲染 `<AgentSwitcher isMiniWindow />`（仅 agent 切换）

**升级方案**（用户确认方案B）：
1. **右下角 AgentSwitcher 改为 agent + model 合一选择器**：
   - 顶部区域：当前 agent 图标 + 名称 + 下拉箭头
   - 下拉菜单内：agent 列表（现有）+ 分隔线 + model 列表（新增）
   - agent 切换：现有逻辑（`setActiveId`）
   - model 切换：复用 `ModelDropdown` 的逻辑（`setSelectedModelId` + apiKeys/hasKeyFor）
   - 组件名改为 `AgentModelSwitcher`（或保留 `AgentSwitcher` 但内容扩展）
2. **移除 AiComposerInput 的 ModelDropdown + AgentSwitcher**（:271-272 删除4行 JSX + 2行 import）
3. **底部状态栏 AiStatusBarControls 移除 ModelDropdown**（:147 删除 `<ModelDropdown />`）
4. **保留底部状态栏的其他控件**（附件/语音/关闭面板/切换窗口/发送）

**改动文件**：
- `src/modules/ai/components/AgentSwitcher.tsx` → 扩展为 agent + model 合一
- `src/modules/ai/components/AiComposerInput.tsx` → 删除 ModelDropdown + AgentSwitcher（-4行 JSX，-2行 import）
- `src/modules/ai/components/AiStatusBarControls.tsx` → 删除 `<ModelDropdown />`（-1行）

**测试**：组件测试 `AgentModelSwitcher.test.tsx`（agent 切换 / model 切换 / hasKey 过滤 / 免 key 恒显示）

**验收**：
- [ ] 输入框旁不再有选择器（更简洁）
- [ ] 底部状态栏不再有 ModelDropdown
- [ ] 右下角 AgentSwitcher 可同时切换 agent 和 model
- [ ] model 选择：有 key 显示 / 无 key 隐藏 / 免 key 恒显示（对齐 P11）
- [ ] `pnpm vitest` 全绿 + `tsc` 0 错误

## 二、P2 · 设置页技能与 MCP 拆分为独立标签（功能性升级 · 中优）

**痛点**：设置页 `SkillsMcpSection` 将 Skills（技能）和 MCP（模型上下文协议）合并为一个标签页，两个功能独立但挤在一起，用户找起来不直观。用户要求拆分为独立标签。

**现状**（源码级）：
- `SkillsMcpSection.tsx`（522 行）包含 5 个 `<section>`：
  1. 技能列表（:130-269）
  2. MCP 服务器列表（:272-365）
  3. MCP 工具详情（:368-436）
  4. 技能详情/编辑（:439-522）
  5. 其他辅助区块
- 设置页标签路由在 `src/settings/store.ts` 中

**升级方案**：
1. **拆分为两个独立标签**：
   - `SkillsSection`（技能）：技能列表 + 技能编辑
   - `McpSection`（MCP）：MCP 服务器列表 + 工具详情
2. **拆分方法**：从 `SkillsMcpSection.tsx` 提取两个子组件，保持现有 UI 样式
3. **i18n**：补 `skills.title`/`skills.description` + `mcp.title`/`mcp.description` 键
4. **路由**：设置页标签新增 skills / mcp 两个入口

**改动文件**：
- `src/settings/sections/SkillsMcpSection.tsx` → 拆分为 `SkillsSection.tsx` + `McpSection.tsx`
- `src/settings/store.ts` → 新增 skills / mcp 标签路由
- `src/lib/i18n/translations.ts` → 补 skills/mcp 独立标题键

**验收**：
- [ ] 设置页有独立的"技能"和"MCP"两个标签
- [ ] 技能标签：技能列表 + 编辑（原 SkillsMcpSection 的技能部分）
- [ ] MCP 标签：MCP 服务器列表 + 工具详情（原 SkillsMcpSection 的 MCP 部分）
- [ ] 功能无回归（技能扫描/MCP 连接/工具列表正常）
- [ ] `pnpm vitest` 全绿 + `tsc` 0 错误
