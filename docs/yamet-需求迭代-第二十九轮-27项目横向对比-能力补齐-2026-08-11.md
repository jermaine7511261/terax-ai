### 3.2 增加 — 多 Provider 容错 / 降级链

**命题**：单个 provider 429/故障时 agent 直接中断，用户体验断裂。

**竞品实证**：
- **daedra**（`E:/Agent/daedra-main`，v0.3.2）：9 后端 fallback 链 + 每后端熔断器（30s cooldown）+ governor 限流 + 指数退避重试。断路器状态：closed→open（30s）→half-open→closed。
- **fetchira**（`E:/Agent/fetchira-main`，v0.1.13）：免费额度感知路由 + 429 自动切换 + 多账号负载均衡 + sticky proxy。`usage` 工具可查剩余额度。
- **GrokSearch-rs**（`E:/Agent/GrokSearch-rs-main`，v0.1.24）：有序源链（Tavily→Exa→TinyFish→Firecrawl）+ 多 Tavily key 轮换 + 故障切换。

**实现路径（本轮交付）**：

#### 3.2.1 Rust 熔断器模块（2 天）

在 `src-tauri/src/modules/ai/` 新增 `resilience.rs`：

```rust
// src-tauri/src/modules/ai/resilience.rs

/// 每 provider 独立熔断器状态
pub struct CircuitBreaker {
    state: BreakerState,          // Closed | Open { opened_at } | HalfOpen
    failure_count: u32,           // 连续失败次数
    success_count: u32,           // HalfOpen 下连续成功次数
    cooldown_ms: u64,             // 默认 30_000ms
    threshold: u32,               // 触发 Open 的失败次数，默认 3
}

/// 降级链：按优先级排列的 provider 列表
pub struct FallbackChain {
    providers: Vec<ProviderEntry>,  // 用户可配置顺序
    default_order: Vec<String>,     // 默认：首选 → OpenRouter → Ollama
}

/// 重试策略
pub struct RetryPolicy {
    max_retries: u32,              // 默认 3
    base_delay_ms: u64,            // 默认 1000
    max_delay_ms: u64,             // 默认 8000
    respect_retry_after: bool,     // 默认 true
}
```

在 `src-tauri/src/modules/ai/client.rs` 的 chat 调用路径中插入 resilience 层：

```rust
// 修改 native.chat() 调用路径
pub async fn chat_with_fallback(
    request: ChatRequest,
    chain: &FallbackChain,
    breakers: &mut HashMap<String, CircuitBreaker>,
) -> Result<ChatResponse, ChatError> {
    for provider in chain.providers.iter() {
        if let Some(breaker) = breakers.get(&provider.id) {
            if breaker.is_open() {
                continue;  // 跳过熔断中的 provider
            }
        }
        match try_chat(provider, &request).await {
            Ok(resp) => {
                breakers.get_mut(&provider.id).map(|b| b.record_success());
                return Ok(resp);
            }
            Err(ChatError::RateLimit(retry_after)) => {
                breakers.get_mut(&provider.id).map(|b| b.record_failure());
                if let Some(delay) = retry_after {
                    tokio::time::sleep(Duration::from_millis(delay)).await;
                }
            }
            Err(e) => {
                breakers.get_mut(&provider.id).map(|b| b.record_failure());
                continue;
            }
        }
    }
    Err(ChatError::AllProvidersFailed)
}
```

**实现路径（本轮交付）**：

#### 3.3.1 fusion 工具（2 天）

在 `src/modules/ai/tools/` 新增 `fusion.ts`：

```ts
// src/modules/ai/tools/fusion.ts
export function buildFusionTools(ctx: ToolContext) {
  return {
    model_fusion: tool({
      description: "多模型融合：同一问题 N 个 provider 并行回答 + judge 综合。用于需要高可靠性的研究问题。",
      inputSchema: z.object({
        query: z.string().describe("研究问题"),
        models: z.array(z.string()).min(2).max(8).describe("参与的模型列表"),
        judge_model: z.string().optional().describe("裁判模型（默认用首选 provider）"),
        web_search: z.boolean().optional().describe("是否允许各模型使用 web 搜索"),
      }),
      execute: async ({ query, models, judge_model, web_search }) => {
        // Phase 1: delegate_many 并行 N 个 general 子 agent（每个用不同 model）
        const results = await delegateMany({
          tasks: models.map(model => ({
            type: "general",
            prompt: query,
            modelId: model,  // 每个 worker 用指定模型
          })),
        });
        // Phase 2: judge 综合
        const judgeResult = await runSubagent({
          type: "general",
          prompt: `你是裁判。以下是 ${models.length} 个模型对同一问题的回答。综合各方观点，给出最准确、最全面的综合答案，标注引用来源。\n\n${results.map((r, i) => `--- 模型 ${models[i]} ---\n${r.summary}`).join("\n\n")}`,
          modelId: judge_model,
        });
        return {
          report: judgeResult.summary,
          panel: results.map((r, i) => ({ model: models[i], answer: r.summary })),
        };
      },
    }),
  };
}
```

## §4 yamet 独有优势（不应稀释）

以下能力在全场 27 个项目中**无人完整复刻**，是 yamet 的护城河：

| 能力 | 实现 | 竞品最接近 | 保护措施 |
|---|---|---|---|
| PTY 多标签终端（WebGL 加速 + 分屏） | portable-pty + xterm.js | grok-build 有 PTY 但无 WebGL | 不替换 xterm.js；新终端后端必须兼容 WebGL 渲染 |
| CodeMirror 6 编辑器 + Vim 模式 + 行内 AI 补全 | CM6 + AI SDK | thClaws 用 CM+tiptap 但仅文件预览 | 不降级为 textarea；行内补全延迟 ≤200ms |
| git 泳道图 | Rust 原生渲染 | **全场唯一** | 不替换为文本 diff；保持泳道可视化 |
| web 预览（自动检测 dev server） | Tauri webview | **全场唯一** | 不替换为外部浏览器；保持内嵌预览 |
| Tauri 2 极致轻量（7-8MB） | Tauri 2 + Rust | oh-my-pi 依赖 Bun；opencode 依赖 Bun+Electron | 每个新依赖 ≤500KB；总二进制 ≤10MB |

**原则**：新增能力不得以牺牲这五项为代价。每个新依赖都要有理由，每个新工具都要过"轻量性"审计。
