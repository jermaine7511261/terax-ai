## 0. 本轮定位（用户命题）

用户聚焦「**AI 迷你窗（AiMiniWindow）**」——一个独立于全屏 AI 面板的浮层窗口。命题：**把这个功能好好构思迭代需求**，对照业界 AI 原生终端/编辑器的浮窗设计（Warp assistant、Claude Code/Codex 内联、VS Code Copilot Chat 浮窗、Ghostty 无边框 UI）找出差距并定稿成可执行需求。

**核心结论**（现状证据见 §2）：迷你窗**基础交互已非常扎实**（拖拽/8 向缩放/几何记忆/会话历史/上下文指示器/plan/todo），但存在真实缺口，其中四项是**主窗口产品缺陷**：
1. **【P0 用户命题】主窗口无 Todo**（`AiChatPanel` 无 Todo 渲染，todo 只在小窗 `AiMiniWindow:273` 可见——新用户建 todo 看不见）；
2. **【P0 用户命题】Edit/Write 无改动内容 + 无折叠**（`tool.tsx` `HEAVY_CONTENT_TOOLS` 拦截 input/output，`hasDetails=false` → CollapsibleTrigger disabled，只显示一行路径摘要，改动内容隐形）；
3. **【P0 用户命题】子 agent 进程不可见**（`run_subagent` 串行阻塞主 agent，内部步骤仅更新一行 `agentMeta.step`，迷你窗无进程视图展示「子 agent 在干什么」）；
4. **【P0 用户命题】主窗口无会话历史 + 无新建**（`AiChatPanel` 无任何 `sessions`/`newSession`/`switchSession` 引用，历史/新建只在迷你窗，主窗口默认 AI 主页却看不到历史话题）；
5. **Mini 窗无内嵌输入框**（`AiMiniWindow.tsx` Body 无 `AiComposerInput`，输入必须依赖全局状态栏 input bar，浮窗场景割裂）；
6. **会话切换丢输入草稿**（composer `value` 全局唯一，切会话不区分）；
7. **浮窗行为单一**（无边缘吸附/双击最大化/pin 置顶，对照现代浮窗工具落后）。

**验收**：三文件同步落地；`pnpm check-drift` 绿。

### P0 · 主窗口展示 Todo（T1/T2，用户命题，最高优先）
1. **主窗口挂载 TodoStrip**：`AiChatPanel`（ChatBody）渲染 `<TodoStrip sessionId={sessionId} />`，复用现有 `TodoStrip` 组件（自包含，只依赖 `todoStore` + sessionId）。
   - **方案 A**：TodoStrip 直接放主窗口会话底部（与迷你窗一致）。**（推荐，最小）**
   - **方案 B**：todo 非空时在会话顶部显示可折叠条（不占空间）。
   - **方案 C**：在主窗口消息流内联渲染（AI 用 todo_write 后紧跟 todo 卡片）。**（增强，需在 AiChat 消息渲染加 tool 分支）**
2. **位置**：主窗口 `AiChatPanel` ChatBody 容器底部（与迷你窗 `Body` 一致，`<div className="flex h-full ..."><AiChatView/><TodoStrip/></div>`）。
3. **迷你窗保留**：迷你窗 TodoStrip 不动（两处共享同一 store 数据，天然一致）。

**验收**：主窗口 AI 用 `todo_write` 建 todo 后，主窗口立即显示进度条 + todo 列表；迷你窗同步显示；`pnpm test` ai 模块绿。

### P0 · Edit/Write 改动展示 + 折叠（E1/E2/E3，用户命题）
1. **主窗口会话显示 Edit/Write 具体改动 + 折叠**：调整 `HEAVY_CONTENT_TOOLS` 处理，让 write_file/edit/multi_edit 在会话中可展开查看改动内容。
   - **方案 A**：从 `HEAVY_CONTENT_TOOLS` 移除 write_file/edit/multi_edit，展示 input（编辑前/写入内容）+ output（结果），复用现有 `Collapsible` 折叠。**（最小，直接）**
   - **方案 B**：保留 heavy 不展示原始 input，但为这三个工具新增**结构化 diff 渲染**（output 含 old/new 或变更行 → 渲染成 diff 视图，可折叠）。**（增强，信息更佳）**
   - **方案 C**：会话内联 tool 卡片底部加「在 diff 中查看」链接（跳 AI diff tab）。**（补入口，不改展示）**
   - **推荐 A（首选，零工具端改动）**：从 `HEAVY_CONTENT_TOOLS` 移除三个工具，展示 input body（edit 的 old/new_string、write 的 content）——**立即解决"看不到写了什么"**；方案 B（结构化 diff，需改工具端输出）作为后续增强。
2. **折叠默认态**：折叠收起（默认 `defaultOpen=false`），用户点击展开查看 diff；有折叠箭头（CollapsibleTrigger 不再 disabled）。
3. **性能**：保留 `memo` 优化（按 state 过渡而非每 token 重渲染）；大 diff 截断（如 200 行）或懒展开。

**验收**：主窗口 AI `edit`/`write_file` 后，会话内 tool 卡片**可折叠展开**查看改动 diff（新增行绿/删除行红或统一 diff 视图）；`pnpm test` ai-elements/tool 相关绿。

### P0 · 迷你窗子 agent 进程视图（A1/A2/A3/A4，用户命题核心）
1. **迷你窗新增「进程/活动」视图**：实时展示子 agent（`run_subagent` / `spawn_coding_agent` / `run_external_agent`）在干什么。
   - **数据源**：新建 `agentActivityStore`（或扩展 `agentMeta` 为活动数组），记录 `{ id, kind: "subagent"|"coding"|"external", type, prompt, status: "running"|"done"|"error", step, startedAt, durationMs, summary }`。
   - **上报**：`subagent.ts`/`agent.ts`/`externalAgent.ts` 执行时 `start`（写活动）→ `onStep`（更新 step）→ `finish`（写 summary/status）。
   - **方案 A（推荐，迷你窗专用）**：`ActivityStrip` 组件放迷你窗（与 TodoStrip/PlanModeStrip 并列），显示运行中 + 最近完成的子 agent 列表，每个含类型徽章 + 实时 step + spinner。
   - **方案 B**：迷你窗 + 主窗口都展示（主窗口也可在会话中内联活动）。
   - **方案 C**：仅顶部通知（复用 LocalAgentNotificationsBridge）。**（太弱）**
   - 推荐 **A**：先迷你窗进程视图（用户命题），主窗口后续。
2. **步骤语义**：`onStep` 从「覆盖单行 step」改为**按活动 id 更新对应行的 step**，支持多个子 agent 并发/连续追踪。
3. **完成态**：运行中 spinner + step；完成显示 `summary`（截断）+ `stepCount` + `durationMs`；错误红色。

**验收**：迷你窗运行 `run_subagent` 后出现进程条目，实时显示当前 step（如 `explore: read_file`）；完成显示 summary；多子 agent 各自独立条目；`pnpm test` ai 模块绿。

### P0 · 主窗口会话历史 + 新建（H1/H2/H3，用户命题）
1. **主窗口（AiChatPanel）新增会话历史列表 + 「+ 新对话」**：接线 store 已有能力（`sessions`/`switchSession`/`newSession`，H3 已完整）。
   - **方案 A（推荐）**：主窗口顶部加**会话栏**——左侧「+ 新对话」按钮 + 会话下拉（复用 `SessionPicker`），右侧历史面板（复用 `HistoryPanel`）；与迷你窗共用组件。
   - **方案 B**：主窗口加**侧栏会话列表**（类 chatgpt 左侧边栏），列出全部历史 + 顶部新建。**（增强，更直观）**
   - **方案 C**：仅「+ 新对话」按钮 + 底部「历史」按钮弹面板。**（最小）**
   - 推荐 **A**（复用小窗组件，最小改动）：主窗口 AiChatPanel 顶部加会话切换（SessionPicker）+ 历史入口（HistoryPanel），底部或顶部「+ 新对话」。
2. **复用**：`SessionPicker`/`HistoryPanel`/`SessionRow` 从 `AiMiniWindow.tsx` 抽出为共享组件（或直接 import 复用），避免重复实现。
3. **新对话行为**：`newSession()` 已支持（chatStore:444 创建并置为 active）；主窗口点「+」即新建并清空输入。

**验收**：主窗口顶部能切换历史会话、看到所有历史话题、点「+ 新对话」新建；与迷你窗会话列表一致；`pnpm test` ai 模块绿。

### P0 · Mini 内嵌输入框（M1/M2）
1. **方案 A**：Mini Body 内嵌 `<AiComposerInput />`（复用全局 `AiComposerProvider` 实例，state 天然同步；全局 input bar 隐藏 Ai 输入时 Mini 仍可用）。
2. **方案 B**：Mini 内嵌独立 composer（新 provider 实例），与全局互不同步。**（不推荐，破坏一致性）**
3. **方案 C**：不内嵌，仅优化全局 input bar 在 Mini 打开时上浮。**（缓解不根治）**
> **推荐 A**：Mini 是独立浮窗，应自带输入；因 `AiComposerProvider` 顶层唯一，Mini 内嵌复用同一 provider 的 state（value/files/snippets 与全局共享），且需处理「全局 input bar 仍显示 Ai 输入」时的重复输入问题。

**验收**：Mini 打开时有输入框，可输入 + `/` 命令 + `@` 文件 + 语音；输入 state 与全局同步（在 Mini 打字、状态栏也显示）；`pnpm test` ai 模块绿。

   - **方案 B**：草稿进 `chatStore`（持久化到 localStorage，重启不丢）。**（增强，需持久化）**
   - **方案 C**：不区分，切会话清空。**（现状，不改）**
> 补充：files/snippets 附件同理可按会话分键（至少 value 必须）。

**验收**：会话 A 输入半句 → 切 B → 切回 A 草稿保留；`composer.test.ts` 新增草稿用例。

### P1 · 边缘吸附 + 双击最大化（F1/F2）

**验收**：`miniWindowGeometry.test.ts` 新增吸附/最大化用例；拖拽到边出现吸附；双击切换最大化。

### P1 · 置顶 pin（F3）

### 4.0.5 Edit/Write 改动展示（方案 A 为主）
- **关键发现**：`edit` 工具 output 是 `{ ok, replacements, bytesWritten, path }`——**无 old/new content**（`edit.ts:14`）；`write_file` output 类似。但 **input 含全部改动内容**（`edit` 有 `old_string`/`new_string`，`write_file` 有 `content`）。
- **方案 A（推荐）**：从 `HEAVY_CONTENT_TOOLS` 移除 write_file/edit/multi_edit，`showInputBody` 为 true → 展示 input 的 old/new/写入内容（复用现有 `ToolInput`/`CodeBlockMini` 渲染），折叠可展开，**立即解决"看不到写了什么"，零工具端改动**。
- **方案 B（可选增强）**：工具端补返回 old/new content，渲染结构化 diff（新增绿/删除红）。需改 `edit.ts`/`fs.ts` 输出 + 前端 diff 渲染。
- **方案 C**：tool 卡片底部「在 diff 中查看」链接跳 AI diff tab。
- 折叠默认收起；`CollapsibleTrigger` 不再 disabled（`hasDetails` 为 true）；保留 memo。

### 4.1 内嵌输入框（方案 A）
- `AiMiniWindow` Body 底部加 `<AiComposerInput />`（复用全局 provider state）。
- 需处理：全局 input bar 与 Mini 同时显示时，避免两个输入框抢焦点——Mini 打开时全局 input bar 的 Ai 输入隐藏（或 Mini 为唯一输入焦点）。

### 4.0.6 子 agent 进程视图（方案 A）
- 新建 `agentActivityStore`（zustand）：`activities: AgentActivity[]`，`start/kick`/`updateStep`/`finish`。
  ```ts
  type AgentActivity = {
    id: string; kind: "subagent"|"coding"|"external";
    type: string; prompt: string; status: "running"|"done"|"error";
    step: string | null; startedAt: number; durationMs?: number; summary?: string;

- `subagent.ts` execute：start → onStep 改调 `agentActivityStore.updateStep(id, step)`（不再覆盖 agentMeta.step）→ finish。`agent.ts`（spawn_coding_agent/send_to_agent/read_agent_output）与 `externalAgent.ts` 同理（coding/external 有 managed-agent/外部进程语义）。

- 接缝：`AiMiniWindow` Body 在 TodoStrip 上方加 `<ActivityStrip sessionId={sessionId} />`。

### 4.2 per-session 草稿（方案 A）

// composer.tsx
const drafts = useRef<Map<string, { value: string; files: FileAttachment[] }>>(new Map());
useEffect(() => {
  const key = sessionId;
  const prev = drafts.current.get(key);
  if (prev) { setValue(prev.value); /* files */ }

  return () => drafts.current.set(key, { value, files });
}, [sessionId]);
```
