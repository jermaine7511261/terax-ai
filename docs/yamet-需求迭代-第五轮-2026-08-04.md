## 三、第五轮新缺口

### U 系列：核心 UX 缺口（P1，用户实际使用反馈）

**U1. AI 会话历史列表缺失**
- 现状：会话数据完备且已持久化（`chatStore.ts` `sessions` + `YaMet-ai-sessions.json` 落盘，`hydrateSessions` 启动加载），但 UI 仅有**一个标题下拉**（`AiMiniWindow.tsx:329` `<SessionPicker />`，定义 `:470-`，DropdownMenu + SessionRow 支持新建/切换/删除/重命名），**没有完整的会话历史面板**：无法一屏浏览全部历史对话、无搜索、无时间分组、无按项目/工作区过滤；旧对话发现性差，容易误以为"没有以前的对话"。
- 方案：AI 面板内加「历史会话」视图（或可折叠侧栏）：按 `updatedAt` 倒序 + 按天分组展示标题/更新时间/消息数；顶部搜索框（过滤 `chatStore.sessions`）；行内复用 SessionRow 的新建/切换/删除/重命名能力；现有标题下拉保留作快捷切换。纯前端 UI 接线，数据已备。

**U2. 工作区文件夹选择入口缺失**
- 现状：后端授权/查询命令齐全（`workspace_authorize`/`workspace_current_dir`，`src/modules/ai/lib/native.ts:168-170`；`App.tsx:1036` 仅在启动时授权启动 cwd；`useWorkspaceSwitcher.ts:48,68` 切换 WSL/Home 时授权）；文件夹选择对话框可用（`@tauri-apps/plugin-dialog` 的 `open`，**唯一使用点**在 `SpaceSwitcher.tsx:21,109-117` `pickRoot`，为每个 space 设置 root，入口藏在空间展开行的文件夹小按钮）。**没有工作区级的「打开文件夹」入口**：命令面板、标题栏、欢迎/首页均无法选择一个任意本地文件夹作为当前工作区（授权 + 派生 explorer root + 开终端到该目录）。
- 方案：新增工作区打开入口（命令面板 `workspace.open` + 标题栏/欢迎页按钮）：`openDialog({ directory: true })` → `workspace_authorize(dir)`（复用 `useWorkspaceSwitcher` 的授权流程）→ 派生 explorer root 并在新 space/终端以 `cwd=dir` 打开。需同时覆盖 `spaces.chooseFolder` 语义的文案统一。
