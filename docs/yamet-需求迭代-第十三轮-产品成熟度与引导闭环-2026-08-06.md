## 0. 本轮定位（用户命题）

用户以「真实用户视角」审视 yamet，结论：**技术地基扎实（8/10），但作为普通用户的工具完成度只有 4/10**。核心短板集中在五类，本轮扩展为七类：

1. **引导闭环缺失**：LSP 已有 enable/install 提示（`src/modules/lsp/lib/useLspHint.ts:10-11`），但 DAP 适配器缺失无引导（`DebugPanel.tsx` 全文无 install 提示）、网关无空状态、首启无「如何开始用」路径。
2. **空状态缺产品语言**：五面板空状态文案简陋或缺失，用户不知道「这里该有什么、下一步点哪」。
3. **可靠性无护栏**：前端 coverage 17.96%（目标 45% 未达 → CI 永久红）、remote/search 零测试、DAP session/transport 零测试、editor/explorer/shortcuts 高频 lib 覆盖极低。
4. **扩展性为零**：无插件系统，新功能只能等官方或改源码。
5. **跨平台体验不均**：Windows 无代码签名首启劝退、Linux Wayland 需手动设 env、i18n parity 曾失守。
6. **高频体验粗粝**（新增）：命令面板仅 23 命令、搜索替换只能整词（`SearchPanel.tsx:77`）、主题仅 10 个、快捷键 93 个无搜索入口、无多窗口/会话分享。
7. **性能与体积**（新增）：eager 353KB 达标但图标集标「不可减瓶颈」，AI 会话历史无导出、无清理引导。

本轮定位「**把用户看得见的短板（引导/空态/高频体验）与看不见的短板（覆盖/测试/扩展边界/性能）一并收口**」。

### P0 · 可靠性护栏落地（主题 3，本轮最硬）

**背景**：coverage 门禁已接，但阈值 45% 当前 17.96% 不满足 → CI 永久红。本轮把「度量」变成「真正生效」的护栏。

1. **coverage 阈值分阶段对齐**（R1）：
   - **方案 A**：设渐进基线 `statements ≥ 25%、branches ≥ 25%、functions ≥ 20%、lines ≥ 25%`，同步补测让数值真实上升（下轮收紧）。
   - **方案 B**：保持 45% 目标不变，本轮高强度补测（editor/explorer/shortcuts/remote/search + DAP 原位），一轮冲到 45%。风险高、周期长。
   - **方案 C**：混合——设 25% 基线 + 补 remote/search/source-control 三个明确目标模块测试，若实测超 25% 提到实测值。**（推荐）**
2. **补 remote/search 零测试**（R2）：抽纯函数补测。
3. **补 Rust DAP session/transport 原位测试**（R3）：fake 适配器 + `timeout_ms` 注入。
4. **补 editor/explorer/shortcuts 高频 lib 纯函数测试**（R4）。
5. **文档**：`docs/contributing/testing.md` 更新覆盖率契约。

**验收**：`pnpm test:coverage` 达标（按所选方案）；CI frontend 绿；remote/search 新增测试；`cargo test dap::` 通过。

### P1 · 引导闭环（主题 1，用户最痛）

## 4. 规划方案（技术设计）

### 4.1 coverage 渐进阈值（多方案见 §3 P0-1）

```ts
// vite.config.ts coverage.thresholds（方案 C 推荐基线）
thresholds: { statements: 25, branches: 25, functions: 20, lines: 25 }
```

不单调低阈值——同步补测。若补测后数值 > 25%，阈值提到实测值，保证「门禁真实生效」。

### 4.2 DAP 适配器探测 + 安装引导

- 接缝：`session.rs` `dap_session_create` 失败时返回 `{ code: "adapter_missing", command }`（`Command::new(adapter_command)` 探测 `which` 语义）。
- 前端 DebugPanel 捕获 → 显示可复制安装命令。
- 复用 LSP `useLspHint` 的 install UI 形态（`src/modules/lsp/lib/useLspHint.ts:11`）。

### 4.3 空状态统一

- `empty.tsx` 增 `EmptyState` 变体：`{ icon, title, description, action?: { label, onClick } }`。
- 五面板 import 并用；文案走 `t()`。

### 4.4 remote/search 纯函数抽取 + 测试

- `RemotePanel.tsx` → `src/modules/remote/lib/sshArgs.ts`：`buildSshCommand(target, action)`、`parseTunnelSpec(spec)`。
- `SearchPanel.tsx` → `src/modules/search/lib/filter.ts`：`filterMatches(hits, query)`、`highlightRanges(text, query)`。
- 各配 `*.test.ts`。

### 4.5 扩展边界固化

- 纯文档：`YAMET.md` 新段 + `ROADMAP.md` 标注。无代码改动。

### 4.6 高频体验

- 命令面板：`commands.ts` 命令加 `keywords`/`description`，`CommandPalette.tsx` 加过滤。
- 搜索替换：`String.replace(query, flags)` 支持正则。
- 主题：`theme/lib/` 加预设 + `settings/store.ts` 加 `THEME_EXPORT`。

### 4.7 会话管理

- `src/modules/ai/lib/sessions.ts` 加 `exportSessions()` / `clearSessions()`（导出 Markdown/JSON，清空带确认）。
- 容量提示：`settings/store.ts` 会话计数 + 阈值提示。

### 4.8 体积死代码审计

- `pnpm knip` 查未用导出 → 安全删除（排除图标集，第十二轮已标不可减）。
