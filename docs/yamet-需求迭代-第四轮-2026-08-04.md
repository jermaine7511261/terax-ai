### 迭代建议（后端在 operations.rs 新增 + commands.rs 挂 `#[tauri::command]`，统一走 `authorized_repo_root` 门控）

**G3 优先（收益最高、改动最小）**：
1. `git_push_upstream(branch)` → `["push","--set-upstream",remote,branch]`（先 `rev-parse @{u}` 判已有）。
2. `git_pull(strategy)` → 支持 `--ff-only` / `--rebase` / `--no-rebase`。
3. `git_create_branch`/`git_delete_branch`/`git_rename_branch` → `["branch",name]` / `["branch","-d",name]` / `["branch","-m",old,new]`。delete 校验 name 非空、非当前分支、不以 `-` 开头（复用 checkout_branch 校验 operations.rs:1138-1140）。
4. 前端 BranchDropdown（SourceControlPanel.tsx:160-342）加 New/Rename/Delete；push NoUpstream 弹"发布分支"；pull 下拉选策略。

**G1 stash**：`git_stash_save(msg)`→`["stash","push","-m",msg]`；`git_stash_list`→`["stash","list"]`（解析 `stash@{n}`）；`git_stash_pop`/`apply(n)`/`drop(n)`。面板 header 加 Stash 按钮 + 列表 apply/pop/drop。

**G2 冲突解决**：
1. 后端 `git_merge_abort`→`["merge","--abort"]`；`git_checkout_ours/theirs`→`["checkout","--ours|--theirs",path]`。
2. 前端筛 `file.statusLabel==="Unmerged"` 生成冲突分组（无需新命令），每文件给保留我/保留远端/打开编辑器 + 全局 Abort merge。
3. **3-way 需新增**：`git_diff_content` 只读 HEAD/index/工作树（operations.rs:229-251），需 `git_show_ours/theirs/base` 或三方 diff 才有完整冲突数据。

**G4 子模块**：status/fetch/pull 增 `--recurse-submodules`（参数开关默认关）；新增 `git_submodule_status`→`["submodule","status"]`（解析 `+`/`-`/`U`）+ `git_submodule_update`→`["submodule","update","--init","--recursive"]`；`resolve_repo` 探测根 `.gitmodules`，`GitRepoInfo` 增 `has_submodules`（types.rs）。
