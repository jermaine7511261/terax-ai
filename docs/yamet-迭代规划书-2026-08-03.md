## 二、迭代项规划

### I1 — 布局/会话持久化（高价值 · P1 → 0.2.0）

**目标**：重启后恢复 tabs / split panels / spaces 结构，并尽量恢复 PTY 会话（每 tab 的 cwd，进阶到 shell 历史）。

**方案**（分阶段，降低风险）：
- **I1a 前端布局持久化**：`useSpaces` + tabs store 加 zustand `persist` middleware，序列化 tabs/panels/spaces 元数据（标签标题、cwd、活动 tab、面板布局）。✅ 基线已内建（`serialize.ts`/`store.ts`/`useSpacePersistence.ts` 经 LazyStore 持久化，已恢复 editor/preview/markdown + 各 space 布局）。
- **I1b PTY cwd 恢复**：启动恢复布局后，每个 tab 用原 cwd 新起 shell（无需后端持久化，先保住工作目录与项目上下文）。✅ `useSpacesBoot` 现恢复 terminal 为 cold tab，激活时以原 cwd 新起 shell。
- **I1c PTY 完整会话恢复**（可选进阶）：后端 pty 会话持久化（会话 id→进程状态，重连/接管），保留 shell 历史与前台进程。⏳ 未实现，列为未来增强。

**参考**：`src/modules/spaces/lib/useSpaces.ts`、`src/modules/tabs/`、pty 模块、VSCode/Windows Terminal 的会话恢复。

**验收**：重启后标签结构与每 tab cwd 恢复（I1a/I1b 已满足）；PTY 历史保留（I1c 可选未做）。
**版本**：0.2.0（✅ 已交付）。

### I2 — 终端拖放（P1 → 随 0.2.0）

**目标**：文件拖入终端 → 插入 shell 引号路径；拖入 AI 面板 → 作为上下文。

**方案**：`fs_copy` 命令已铺路（`fs/mutate.rs`），前端补终端 drop 处理器，将文件路径 shell-quote 后插入输入行；AI 面板拖入走 `run_subagent` 或上下文注入。

**参考**：`fs/mutate.rs`、`terminal/block/ShellInput.tsx`。

**验收**：拖入 `.md`/`.ts` 文件进终端插入正确引号路径；拖入 AI 面板追加为上下文。
**版本**：0.2.0（随 I1 或独立提交）。

---

### I3 — SSH 支持（P2 · ROADMAP 首项 → 0.3.0）

**目标**：远程终端。**第一阶段** PTY auth + known_hosts；SFTP 与端口转发后置。

**方案**：Rust 后端引入 `ssh2` crate（基于 libssh2/openssl），新建 `modules/ssh`：主机/凭据配置、known_hosts 管理、密码/密钥认证、SSH→PTY 桥接。前端复用现有 PTY 渲染。

> **实现决策（已落地）**：改用 **spawn 系统 `ssh` 客户端作为 PTY 子进程**（`modules/ssh/target.rs` 构造 argv），而非引入 `ssh2`/openssl。known_hosts 校验（`StrictHostKeyChecking=ask`，未知主机在 PTY 内提示 `yes` 记录）、密码/密钥/agent 认证全部由系统 ssh 原生处理，且复用 100% 现有 pty 基建（reader/flusher/block/agent-detect），零新依赖、规避打包体积风险。与 VS Code / Windows Terminal 的远程终端同路径。

**参考**：`src/modules/ssh/target.rs`（命令构建+sanitize 防注入）、现有 `modules/pty` 架构、Windows Terminal SSH。

**验收**：✅ 能连远程主机开 PTY 终端、known_hosts 指纹校验、密码与 key 认证、断线重连（`ssh` 客户端原生）。前端 `+` 菜单新增 SSH 连接对话框（host/user/port/私钥），标签持久化 round-trip 后重启重连。
**版本**：0.3.0（✅ 已交付）。

## 五、风险与依赖

- **PTY 会话恢复**：进程状态持久化 + 重连复杂，MVP 先恢复布局+cwd，完整会话恢复列为可选。
- **SSH**：`ssh2`/openssl 依赖增大打包体积，需评估 Windows 交叉编译；known_hosts 指纹信任需安全默认。
- **外部 agent 编排**：CLI 探测/版本漂移；审批与权限边界需清晰。
- 所有功能性版本改动后必须过 `pnpm check-types` + `pnpm test`（509 项）+ `cargo test` + 完整构建验证。
